Politique de confidentialité de Trusti

Dernière mise à jour : 8 octobre 2026

Trusti (eu.trusti.app) est une application qui évalue la fiabilité et le respect de la vie privée d'autres applications, et vous aide à trouver des alternatives plus respectueuses. Cette page explique quelles données Trusti traite, pourquoi, et comment les contrôler. Elle couvre l'application Android et le site trusti.lielu.eu.

En résumé : l'application Android Trusti ne crée aucun compte, ne vous demande aucune donnée personnelle et n'en envoie aucune à nos serveurs. Aucun suivi publicitaire, aucun outil d'analyse, aucune revente de données.

Application Android

  • Aucun compte, aucune connexion : l'application ne propose pas de connexion. Nous ne collectons ni adresse e-mail, ni nom, ni identifiant, ni localisation.
  • Liste de vos applications installées : pour afficher leurs notes, Trusti repère sur votre téléphone lesquelles de ses applications du catalogue sont installées. Cette analyse est faite uniquement sur votre appareil ; la liste n'est jamais transmise.
  • Espace de stockage (facultatif) : si vous activez dans les réglages Android l'accès à l'utilisation, Trusti lit la taille occupée par ces applications pour l'afficher. Ces informations restent sur votre appareil.
  • Vos choix et préférences (applications sélectionnées, réglages) sont stockés uniquement sur votre appareil.
  • Connexion réseau : l'application consulte notre catalogue d'évaluations (public et anonyme) pour afficher les notes. Comme pour toute requête internet, l'hébergeur (Vercel) peut enregistrer techniquement l'adresse IP et la date de la requête pour assurer la sécurité du service ; nous n'utilisons pas ces données pour vous identifier ni vous suivre.

Site web (trusti.lielu.eu)

  • Le site peut être utilisé sans compte. Une connexion facultative est proposée : vous saisissez votre adresse e-mail et nous vous envoyons un code à usage unique (OTP) à 6 chiffres pour la vérifier. Cette adresse est alors enregistrée dans notre base de données, uniquement pour vous permettre de vous reconnecter. Aucun mot de passe n'est demandé ni stocké.
  • Votre sélection d'applications et vos préférences sont stockées uniquement dans le navigateur, jamais transmises à nos serveurs.

Pourquoi nous traitons ces données

  • L'adresse e-mail (site web uniquement, si vous vous connectez) sert exclusivement à l'authentification par code à usage unique.
  • Aucune donnée n'est utilisée à des fins publicitaires, de profilage ou de revente à des tiers.

Avec qui nous partageons des données

Pour l'envoi du code de connexion du site web, nous utilisons un prestataire d'envoi d'e-mails (Brevo), qui reçoit votre adresse e-mail dans ce seul but. L'application Android n'utilise pas ce service. Nous ne partageons vos données avec aucun autre tiers, et ne les vendons jamais.

Hébergement et sécurité

Les adresses e-mail des comptes du site web sont hébergées sur une base de données PostgreSQL gérée par Neon. Le catalogue et le site sont hébergés sur Vercel. Les échanges sont chiffrés (HTTPS).

Vos droits

Vous pouvez utiliser Trusti sans jamais créer de compte. Si vous vous êtes connecté sur le site web et souhaitez faire supprimer votre adresse e-mail de notre base de données, contactez-nous à l'adresse ci-dessous — nous la supprimons sous 30 jours. Sur l'application Android, désinstaller Trusti ou effacer ses données supprime tout ce qu'elle stocke.

Enfants

Trusti ne cible pas spécifiquement les enfants et ne collecte sciemment aucune donnée personnelle d'enfants.

Modifications de cette politique

Cette page peut être mise à jour si le fonctionnement de l'application évolue. La date de dernière mise à jour est indiquée en haut de cette page.
